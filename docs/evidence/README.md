# Verification evidence — simulated only

These files were generated by executing `run_verification.py` and `scripts/verify_browser.py`
on the original CubeRace: System-1 vs LLM implementation. They are reproducible functional
checks, not empirical results for the assigned OpenRouter models.

- `pytest-output.txt`: 183 passing offline tests and one dependency deprecation warning.
- `ruff-output.txt`: executed lint output.
- `verification.json`: five-puzzle / 20-trial functional summary, zero paid requests.
- `simulated-suite.json`: full persisted run schema, events and synthetic-agent provenance.
- `simulated-suite.csv`: one row per model slot / puzzle trial.
- `simulated-suite.steps.csv`: every executed synthetic action and resulting state.
- `simulated-suite.requests.csv`: header only because simulation makes no API requests.
- `browser-verification.json`: actual headless Edge flows and viewport measurements.
- PNGs: actual screenshots at laptop, desktop and mobile sizes; in-progress/completed race,
  analysis and presentation. Identity is intentionally unset and visibly flagged.

Backend verification and browser verification use independent temporary databases and runs;
their run IDs and local elapsed times therefore differ. No generated simulation timing is
attributed to a real model. Live evidence must be collected separately with private credentials
and explicit spending confirmation. Runtime data and credentials are excluded from Git.
